# Contributing to PoE2 Runbook

Thank you for helping. Bug reports, ideas, translations, plans and code are welcome.

- **A bug:** open an [issue](https://github.com/LABUTIN-OU/poe2-runbook/issues/new/choose) with the bug report form and attach `program.log`.
- **A change:** open a [pull request](https://github.com/LABUTIN-OU/poe2-runbook/pulls) with one change, and run the tests first (see `README.md`).
- **A vulnerability:** do not open a public issue — [report it privately](https://github.com/LABUTIN-OU/poe2-runbook/security/advisories/new), see
  `SECURITY.md`.

## How to agree

Put this line into the description of your pull request — the pull request template already holds it as a box to
tick:

    I have read the Contributor Agreement in CONTRIBUTING.md and I agree to it for this contribution and for my later contributions to PoE2 Runbook.

мере, в какой вклад их затрагивает. Автор, взяв вклад в программу, лицензирует его и на условиях лицензии, которая
была у программы в день отправки вклада. Участник подтверждает, что вклад — его собственный или что у него есть право
его передать, а если часть взята у кого-то ещё — называет источник и лицензию. Автор не обязан брать вклад; вклад
передаётся «как есть», без гарантий.

отметить. Юридическую силу имеет английский текст.
