# Path of Exile 2 game data

Every file in this folder is built by `catalog/build.py` from the data of Path of Exile 2 (version 0.5.5.10): zones, item bases, affixes, gems, unique items, names and log lines in the languages of the game. The raw game tables are not in the repository; how to get them is described in `catalog/dat_pack.py` and `catalog/build.py`.

This data belongs to Grinding Gear Games. The licence of PoE2 Runbook (`LICENSE`, `NOTICE.md` in the root of the
repository) does not cover it. It is here so that the program and its tests work right after cloning.

This product isn't affiliated with or endorsed by Grinding Gear Games in any way.

## Данные игры Path of Exile 2

Все файлы этой папки собраны программой `catalog/build.py` из данных Path of Exile 2 (версия 0.5.5.10): зоны, базы предметов, аффиксы, камни, уникальные предметы, названия и строки лога на языках игры. Исходных таблиц игры в репозитории нет; как их получить, описано в `catalog/dat_pack.py` и `catalog/build.py`.

Эти данные принадлежат Grinding Gear Games, лицензия программы PoE2 Runbook (`LICENSE`, `NOTICE.md` в корне
репозитория) на них не распространяется. Они лежат здесь, чтобы программа и её тесты работали сразу после
клонирования.
