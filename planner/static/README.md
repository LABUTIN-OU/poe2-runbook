# Path of Exile 2 game data

The JSON files in this folder are built from the data of Path of Exile 2: the passive skill tree (`tree.json`, by `planner/treegeo.py`) and the Atlas tree (`atlas.json`, by `planner/atlasgeo.py`) with what each node gives in the languages of the game (`treestats*.json`, `atlasstats*.json`). The pages (`*.html`) are part of the program and are covered by its licence.

This data belongs to Grinding Gear Games. The licence of PoE2 Runbook (`LICENSE`, `NOTICE.md` in the root of the
repository) does not cover it. It is here so that the program and its tests work right after cloning.

This product isn't affiliated with or endorsed by Grinding Gear Games in any way.

## Данные игры Path of Exile 2

JSON-файлы этой папки собраны из данных Path of Exile 2: дерево пассивных умений (`tree.json`, собирает `planner/treegeo.py`) и дерево атласа (`atlas.json`, собирает `planner/atlasgeo.py`), а также что даёт каждый узел на языках игры (`treestats*.json`, `atlasstats*.json`). Страницы (`*.html`) — часть программы, на них лицензия программы распространяется.

Эти данные принадлежат Grinding Gear Games, лицензия программы PoE2 Runbook (`LICENSE`, `NOTICE.md` в корне
репозитория) на них не распространяется. Они лежат здесь, чтобы программа и её тесты работали сразу после
клонирования.
