# Сайт программы: из чего он собирается, чем проверяется, как переснять картинки

Сам сайт — папка `site/`: готовые статичные файлы, выкладывается целиком, как есть. Здесь — образец главной,
исходники страниц, инструменты и снимки для просмотра; на сайт отсюда попадает только то, что пишут `build_site.py`,
`pack_shots.py` и `make_og.py`. Всё на стандартной библиотеке Python; для картинок нужны Chrome и Pillow.

`<work>` ниже — любая пустая временная папка (пробные данные, профиль Chrome).

## Образец главной

`mock/` — образец главной страницы, каким его правят сейчас (`index.html`, `mock.css`, как он выглядит — `mock/look/`).
**Главная сайта = образец:** порядок, размеры, отступы, цвета, слова.

`src/sample/` — та версия образца, на которой сайт стоит. **Слова русской главной нигде больше не записаны:** сборка
берёт `<main>` из `src/sample/index.html` и ставит в него живые части — ссылки на установщик, строку под первой кнопкой
и блок выпуска (их заполняет `site.js` из `update/latest.json`), свои снимки программы вместо картинок образца, адреса
вместо ссылок «#», скрытый раздел «Готовые планы» (`src/plans.html`) перед полосой для авторов. Заголовок вкладки,
описание страницы и описание картинки для ссылок — тоже из образца. Стили сайта берут `mock.css` оттуда слово в
слово; своё дописано в `src/extra.css`.

Взять новую версию образца — одна команда; она называет, какие куски текста ушли и какие пришли:

    python -X utf8 work/site/tools/build_site.py . --take

Сборка остановится и скажет, чего ей не хватает, если в образце появилась картинка, которой нет в таблице `PICS`
(ей нужен свой снимок — `make_shots.py`), или ссылка «#», которой нет в таблице `LINKS` (ей нужен адрес); обе таблицы —
в начале `build_site.py`. Поменялась ширина показа картинки — поправить числа в начале `make_shots.py` и `pack_shots.py`.

Сверить с образцом экран за экраном:

    python -X utf8 work/site/tools/compare_mock.py . http://127.0.0.1:4756 <work>/overlay <work>/compare <work>/chrome 4757
    python -X utf8 work/site/tools/compare_mock.py . http://127.0.0.1:4756 <work>/overlay <work>/compare-live <work>/chrome 4757 --live

Первая — с `src/sample/` (должно остаться одно названное отличие: язык в шапке — список, а не ссылка). Вторая — с
`mock/`: насколько образец ушёл вперёд. Сверка идёт по всему видимому на странице по порядку (место, размер, шрифт,
цвет, слова) на ширинах 1280, 500 и 390 и кладёт пары экранов «образец слева, сайт справа».

## Языки

Какие языки есть, как они себя называют и как пишут числа и даты — читается из программы (`planner/lang/*.json`), в её
порядке. Английский стоит в корне сайта — это общий адрес; остальные — в своих папках (`/ru/`, `/de/`, `/pt/` …).
В шапке — название текущего языка, под ним список всех языков сайта (текущий отмечен). Общий адрес без выбора ведёт на
первый из языков браузера, который есть на сайте; выбор в списке запоминается.

**Язык попадает на сайт, когда у него есть всё:**

1. слова оболочки и названия внутренних страниц — `src/words.<код>.json`;
2. три внутренние страницы — `src/safety.<код>.html`, `src/install.<код>.html`, `src/about.<код>.html`;
3. главная — `src/overview.<код>.json`: таблица `{"русский кусок текста образца": "перевод"}` на каждый кусок
   (перечень кусков — `build_site.py . --units`). Изменилось предложение в образце — перевода у него больше нет, и
   сборка называет его;
4. семь картинок программы `<имя>-<код>.webp` и картинка для ссылок `og-<код>.png` в `site/assets`.

Чего языку не хватает, сборка называет в конце; такого языка на сайте нет вовсе — ни адреса, ни строки в списке.
Как переводить и что нельзя трогать — `TRANSLATE.md`. Проверить перевод до сборки (полнота, разметка тег в тег с
русским файлом, места для чисел, метки, не осталось ли русского текста):

    python -X utf8 work/site/tools/check_lang.py . de es fr ja ko pt th

Слова программы (названия её кнопок и вкладок) в тексте ставятся меткой `{{ui Русское название}}` — сборка берёт
перевод из языкового файла программы и останавливается, если такого слова у программы нет; игровые названия — из
каталога данных игры. Страница `404.html` собирается тоже (`src/404.html`): ссылки на первую страницу каждого языка.

Посмотреть сайт на всех языках программы, пока у какого-то из них текстов нет (недостающее занимается у английского):

    python -X utf8 work/site/tools/build_site.py . --trial <work>/nine
    python -X utf8 work/site/tools/serve.py site 4753 <work>/nine

## Страницы

Собираются из `src/`: `layout.html` — общая оболочка (шапка без вкладок, подвал со ссылками, `<head>`), `pages.json` —
перечень страниц и их адреса, `words.<код>.json` — слова оболочки и названия страниц, `<страница>.<код>.html` —
собственный текст внутренней страницы, `sample/mock.css` + `extra.css` — стили. **Правится в `src/`, не в `site/`:** следующая сборка перепишет страницу и
`site/assets/site.css`.

    python -X utf8 work/site/tools/build_site.py .            # собрать
    python -X utf8 work/site/tools/build_site.py . --check    # ничего не менять; сказать, чем site/ отличается от src/

Сборка ставит неразрывный пробел перед тире (ни одна строка не начинается с тире) и останавливается, если на странице
осталась метка `{{…}}`, есть встроенный стиль или скрипт (их запрещает Content-Security-Policy страниц), путь от корня
или ссылка / якорь, который никуда не ведёт.

Скрипты (`site/assets/site.js`, `lang.js`, `config.js`), `CNAME`, примеры `update/latest.example.json` и
`plans/index.example.json` — обычные файлы в `site/`, правятся там. Настройки сайта — `site/assets/config.js`: адрес
репозитория, контакт и, когда репозиторий открыт, раздел его задач (`issues`).

## Картинки программы

С пробной копии программы, вымышленный герой, порты 4751–4759; наружу пробная копия не ходит (`--offline`). Один
запуск — один язык (любой из языков программы): лог, название класса героя и тексты предметов пробного героя пишутся
на этом языке клиента словами игры из каталога, страницы программа показывает на языке клиента сама.

    xcopy /e /i planner <work>\prog\planner
    python -X utf8 work/site/tools/make_shots.py <work>/prog . <work> <work>/raw ru 4751
    python -X utf8 work/site/tools/make_shots.py <work>/prog . <work> <work>/raw en 4752
    python -X utf8 work/site/tools/pack_shots.py <work>/raw site/assets ru en de es fr ja ko pt th
    python -X utf8 work/site/tools/make_og.py . <work> 4759
    python -X utf8 work/site/tools/build_site.py .

Два запуска одновременно — в разных `<work>` (у каждого свой профиль Chrome) и на разных портах.

Семь картинок на язык, каждая снята вдвое плотнее самого крупного показа (ничего не пересчитывается): `list` — список
шага, 1664 px (показ до 832), снимается в ту секунду, когда время шага — 1:26: его называет описание картинки на
странице; `window` — окно программы со страницей «Игра», 2080 px (до 1040; на телефоне окно не уменьшается, а
обрезается справа — стилем); `late` — тот же список с одной опоздавшей целью, первые строки крупно, 1984 px (до 992);
`answer` — ответ на копию предмета, 1120 px (до 560); `tiles` — три плитки времени страницы «Игра», 2080 px (до 1040,
на телефоне обрезается справа); `time` — «Разбор», 1752 × 984 (до 876); `plan` — «Редактор», 1040 × 584 (до 511).
Сохраняются WebP без потерь. `make_og.py` рисует картинку для ссылок 1200 × 630 на каждый язык: заголовок главной
(русский — из образца, остальные — из таблицы перевода) и список шага; длинный заголовок ставится мельче.

План в пробной копии — тот, что идёт с программой, как есть: его собственные слова (названия шагов и этапов) программа
с 0.5.5.23 переводит сама (раздел `plan` её языковых файлов), так что кадр показывает то, что увидит игрок этого языка.

Рядом с каждой картинкой съёмка пишет весь видимый в её рамке текст (`<имя>-<код>.txt`, вместе со значениями полей
редактора). По нему проверяется, нет ли в кадрах слов не на языке страницы:

    python -X utf8 work/site/tools/words_check.py . <work>/raw

Кириллица на нерусской странице; латиница на русской, японской, корейской, тайской, если клиент игры этого языка
сам так не пишет; английское название игры там, где у клиента есть своё. Не в счёт: имена, данные людьми (план
«HC SSF · DoV», герой «Trial»), английское имя в скобках после местного («Колокольщик (The Crowbell)» — программа
ставит пару нарочно), слова самого перевода программы («Build»), код языка на её кнопке.

## Посмотреть сайт локально

Как его отдаст хостинг (404.html на отсутствующий адрес, без кеша):

    python -X utf8 work/site/tools/serve.py site 4756 <work>/overlay

Файл из `<work>/overlay` отдаётся вместо файла сайта (и страница папки тоже): так пробуют `update/latest.json`,
`plans/index.json`, другой `assets/config.js` и пробную сборку всех языков, не создавая их в `site/`.

В панели браузера приложения — через свою временную запись в `.claude/launch.json`. Файл общий, и другая сессия
может держать там запись с любым именем, поэтому имя берётся своё, а инструмент чужую запись не заменяет и не снимает:

    python -X utf8 work/site/tools/launch_entry.py .claude/launch.json add <своё имя> <serve.py> <site> 4756 <work>/overlay
    python -X utf8 work/site/tools/launch_entry.py .claude/launch.json remove <своё имя> <work>/overlay

## Проверки

Сервер на 4756 должен работать (второй инструмент поднимает свой сам):

    python -X utf8 work/site/tools/site_checks.py http://127.0.0.1:4756 <work>/overlay site <work>/checks <work>/chrome 4757
    python -X utf8 work/site/tools/lang_checks.py . <work>/nine work/site/preview/nine <work>/chrome 4753 4757
    python -X utf8 work/site/tools/site_shots.py http://127.0.0.1:4756 work/site/preview <work>/chrome 4757

Первая — поведение сайта на русском и английском: `site/` совпадает со сборкой; язык на каждой странице и список
языков; общая шапка и подвал, одна тёмная тема; «Скачать» во всех состояниях на всех страницах — каждая кнопка
сразу отдаёт установщик, когда сборка известна; главная против образца — те же блоки в том же порядке, столько же
вопросов и картинок (у русской и слов), куда ведут ссылки ответов; первый экран, ни одна строка не начинается с
тире, плотность картинок; строки страницы «Что программа читает» и раскрытия; беды первого запуска на «Установке»;
«Готовые планы» (в том числе враждебные значения в их файле); настройки; страницы без JavaScript; 404; открытие с
диска; ссылки. Вторая — то, что у языков общее, на всех языках программы: адрес каждой из четырёх страниц, название в
шапке и список, hreflang, свои картинки, дата по-своему, шапка на телефоне (название языка, которое не помещается,
заменяется кодом), выбор по языку браузера и запоминание выбора, и что страница написана своими словами — не
английским текстом и без русских слов. Третья — снимки и меры всех страниц всех языков (1280 и 390): что каждая
запросила, не прокручивается ли вбок, её высота и число слов; главная каждого языка — целиком на обеих ширинах,
русская и английская ещё и экранами 1280 × 800.

**Сверить текст сайта с кодом программы** — таблица «утверждение → файл:строка» по коду, какой он сейчас;
якорь, которого в коде больше нет, назван в конце:

    python -X utf8 work/site/tools/claims.py .

`preview/` — снимки страниц на 26.11.2026 (сборка 0.5.5.22): главная каждого языка `overview-<код>-1280.png` и
`-390.png`, внутренние страницы, `report.json` с мерами, пары «образец — сайт» (`compare-*.png`) и `nine/` — первый
экран каждого языка с открытым списком языков.
