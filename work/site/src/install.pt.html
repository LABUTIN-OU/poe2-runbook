Como conferir o arquivo e o que o Windows vai perguntar

A primeira versão pública ainda não foi publicada.

Ela vai aparecer aqui: o programa só é baixado deste site.

Primeira execução

O instalador ainda não está assinado, por isso o Windows não conhece o fornecedor dele. No lugar da assinatura há o SHA-256 ao lado do botão “Baixar”: ele mostra que o seu arquivo é o mesmo que está publicado nesta página.

Não tenho certeza de que o arquivo é o verdadeiro

O arquivo verdadeiro se reconhece pelo SHA-256. Abra a pasta com o arquivo baixado, clique na barra de endereços do Explorador de Arquivos, digite powershell e pressione Enter. Na janela que abrir, execute:

Get-FileHash "PoE2Runbook-Setup-*.exe"

Compare o valor abaixo da palavra Hash com o SHA-256 ao lado do botão “Baixar”. Todos os 64 caracteres precisam coincidir; maiúsculas ou minúsculas, tanto faz. Se não coincidir, não execute o arquivo: baixe-o de novo nesta página.

O Windows não deixa executar o instalador

O instalador ainda não está assinado, e o Windows não conhece o fornecedor dele. Vai aparecer a janela “O Windows protegeu o computador”. Clique em “Mais informações” e depois em “Executar assim mesmo”.

O navegador pode avisar ainda antes: um arquivo assim é baixado raramente. Mantenha o arquivo mesmo assim.

No Windows 11 com o “Controle Inteligente de Aplicativos” ativado, o botão “Executar assim mesmo” não existe: essa proteção bloqueia o instalador de vez.

Não tenho direitos de administrador

Eles não são necessários. O instalador instala o programa só para você — na pasta %LOCALAPPDATA%\Programs\PoE2 Runbook.

O programa não encontrou o jogo

O programa procura o jogo sozinho: Steam ou o cliente do site do jogo, em qualquer disco. Se não encontrar, ele avisa e deixa você indicar a pasta do jogo.

O que é preciso

  • Windows 10 ou Windows 11, de 64 bits.
  • Microsoft Edge WebView2 — no Windows 11 ele já vem; no Windows 10, quem o instala é o Windows Update. Se ele faltar, o programa avisa e oferece a página de download da Microsoft.
  • Path of Exile 2. Cada versão do programa é feita para uma única versão do jogo — ela é indicada ao lado do botão “Baixar”.
  • O jogo no modo “Janela” ou “Tela Cheia em Janela” — para as janelas sobre o jogo.

Atualização

O próprio programa avisa quando há uma versão nova e a instala pelo botão “{{ui Обновить}}”. A versão nova é instalada por cima da anterior: os seus planos e heróis ficam.

Idiomas do programa

{{program_langs}}.

O programa lê o log do jogo em qualquer um desses idiomas do cliente.

Desinstalação

Nas Configurações do Windows: “Aplicativos” → PoE2 Runbook → “Desinstalar”.

A pasta com os seus planos e heróis — %APPDATA%\PoE2 Runbook — fica no lugar. Se não precisar dela, apague-a você mesmo.
