リリースされると、ここに表示されます。プログラムをダウンロードできるのは、このサイトだけです。

初回起動

インストーラーにはまだ署名がないため、Windows は発行元を認識できません。署名の代わりになるのが、「ダウンロード」ボタンの横にある SHA-256 です。あなたのファイルが、このページで公開されているものと同じであることを示します。

ファイルが本物か不安です

本物のファイルは SHA-256 で見分けられます。ダウンロードしたファイルのあるフォルダーを開き、エクスプローラーのアドレス バーをクリックして powershell と入力し、Enter を押します。開いたウィンドウで、次を実行します：

Get-FileHash "PoE2Runbook-Setup-*.exe"

Hash の下に表示された値を、「ダウンロード」ボタンの横の SHA-256 と比べてください。64文字すべてが一致していなければなりません。大文字か小文字かは関係ありません。一致しない場合は、ファイルを実行しないでください。このページからダウンロードし直してください。

Windows がインストーラーを起動させてくれません

インストーラーにはまだ署名がなく、Windows は発行元を認識できません。「Windows によって PC が保護されました」というウィンドウが表示されます。「詳細情報」をクリックし、次に「実行」をクリックしてください。

ブラウザーが、それより先に警告することもあります。このようなファイルは、ダウンロードされることが少ないためです。それでも保存してください。

「スマート アプリ コントロール」がオンの Windows 11 には、「実行」ボタンがありません。この保護機能は、インストーラーを完全にブロックします。

管理者権限がありません

必要ありません。インストーラーは、プログラムをあなたのユーザーアカウントにだけインストールします。インストール先は %LOCALAPPDATA%\Programs\PoE2 Runbook フォルダーです。

ゲームが見つかりません

プログラムはゲームを自分で探します。Steam 版でも、ゲーム公式サイトのクライアントでも、どのドライブにあっても探します。見つからなかった場合は、そのことを知らせ、ゲームフォルダーを指定できるようにします。

必要なもの

  • Windows 10 または Windows 11（64 ビット版）。
  • Microsoft Edge WebView2。Windows 11 には入っており、Windows 10 には Windows Update がインストールします。入っていない場合は、プログラムがそう知らせ、Microsoft のダウンロードページを案内します。
  • Path of Exile 2。プログラムの各ビルドは、ゲームの1つのバージョンに合わせて作られています。そのバージョンは、「ダウンロード」ボタンの横に書かれています。
  • ウィンドウモードまたはウィンドウフルスクリーンモードのゲーム。「{{ui Окна поверх игры}}」に必要です。

更新

新しいバージョンが出ると、プログラムが自分で知らせ、「{{ui Обновить}}」ボタンでインストールします。新しいバージョンは、前のバージョンに上書きされます。あなたのプランとヒーローは残ります。

プログラムの言語

{{program_langs}}.

クライアントの言語がこのうちのどれであっても、プログラムはゲームのログを読み取れます。

アンインストール

Windows の「設定」→「アプリ」→ PoE2 Runbook →「アンインストール」。

あなたのプランとヒーローが入ったフォルダー（%APPDATA%\PoE2 Runbook）は、そのまま残ります。不要なら、自分で削除してください。
