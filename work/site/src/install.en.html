How to verify the file, and what Windows will ask

The first public build is not published yet.

It will appear here: the program is downloaded only from this site.

First start

The installer isn't signed yet, so Windows doesn't know its publisher. Instead of a signature there is the SHA-256 next to the Download button: it shows that your file is the one published on this page.

I'm not sure the file is the real one

The real file is known by its SHA-256. Open the folder with the downloaded file, click the address bar of File Explorer, type powershell and press Enter. In the window that opens run:

Get-FileHash "PoE2Runbook-Setup-*.exe"

Compare the value under Hash with the SHA-256 next to the Download button. All 64 characters must match; upper or lower case doesn't matter. If they differ, don't run the file: download it again from this page.

Windows won't let me run the installer

The installer isn't signed yet, so Windows doesn't know its publisher. A window “Windows protected your PC” appears. Click “More info”, then “Run anyway”.

Your browser may warn you even earlier: such a file is rarely downloaded. Keep it anyway.

On Windows 11 with Smart App Control turned on there is no “Run anyway” button: that protection blocks the installer outright.

I have no administrator rights

You don't need them. The installer puts the program in for you alone — into the folder %LOCALAPPDATA%\Programs\PoE2 Runbook.

The program didn't find the game

The program looks for the game itself: Steam or the standalone client, on any drive. If it doesn't find it, it says so and lets you point to the game's folder.

What it needs

  • Windows 10 or Windows 11, 64-bit.
  • Microsoft Edge WebView2 — part of Windows 11; Windows 10 receives it through Windows Update. If it is missing, the program says so and offers Microsoft's download page.
  • Path of Exile 2. Each build of the program is made for one version of the game — the one named next to the Download button.
  • The game in windowed or windowed fullscreen mode — for the windows over the game.

Updating

The program tells you about a new version itself and installs it when you press {{ui Обновить}}. A new version goes over the old one: your plans and heroes stay.

Languages of the program

The program reads the log of a game client in any of these languages.

Removal

In Windows Settings: Apps → PoE2 Runbook → Uninstall.

The folder with your plans and heroes — %APPDATA%\PoE2 Runbook — stays in place. Delete it yourself if you do not need it.
