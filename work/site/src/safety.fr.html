Ce que le programme lit, écoute et presse

Une fenêtre à part, à côté du jeu : le programme lit le journal et les options du jeu, écoute trois touches et envoie au jeu une seule copie d’objet pour chacun de vos appuis sur F2. Dans le jeu lui-même, il ne modifie rien : ni fichiers, ni mémoire.

Chaque ligne ci-dessous est tirée du code du programme. Une ligne avec une flèche se déplie.

Ce qu’il lit : les fichiers du jeu

  • logs\Client.txtLe journal du jeu. Lecture seule : zone, niveau du héros, récompenses.
    Il se trouve dans le dossier du jeu. Au lancement, tout le journal est lu ; ensuite, seulement les nouvelles lignes, deux fois par seconde. Ce qui en est tiré : le lancement et la fermeture du jeu ; la zone où vous entrez ; le niveau du héros — ces lignes donnent le nom et la classe du héros ; les récompenses de quête ; la mort du héros ; le filtre d’objets que le jeu a chargé ; vos clics dans l’arbre des talents passifs ; la version du jeu. De tout ce qui se dit dans le chat, seules sont relevées les répliques de PNJ qu’attend votre plan ; le reste n’est pas conservé.
  • poe2_production_Config.iniLes options du jeu. Lecture seule : filtre, langue, touches du jeu.
    Il se trouve dans Documents\My Games\Path of Exile 2 ; il est relu quand le fichier change. Ce qui en est tiré : le filtre d’objets sélectionné, la langue du client et les touches assignées dans le jeu — pour que les touches du programme n’occupent pas une touche dont le jeu se sert.
  • OnlineFilters\Les filtres d’objets de votre compte. Lecture seule.
    Un dossier dans Documents\My Games\Path of Exile 2 : les filtres que le jeu a téléchargés depuis votre compte. Le nom et les règles de chacun sont lus — pour appeler le filtre par son nom et vous prévenir quand le filtre sélectionné masque un objet que cherche le plan. Une copie de chaque version de filtre chargée par le jeu reste dans le dossier du programme lui-même.
  • Fichiers Steam et Registre WindowsLecture seule, pour trouver où le jeu est installé.
    libraryfolders.vdf, appmanifest_2694490.acf ; dans le Registre : le dossier de Steam et l’entrée « Path of Exile 2 » parmi les programmes installés. Jeu introuvable ? Vous indiquez le dossier vous-même.

Ce qu’il demande à Windows

  • La fenêtre activeLaquelle est devant, et à qui elle est. La mémoire du jeu n’est pas lue.
    Quelle fenêtre est au premier plan en ce moment et à quel programme elle appartient — pour savoir que c’est le jeu.
  • La fenêtre du jeu, le curseur, AltOù ils se trouvent en ce moment. Rien n’est lu à l’écran.
    Où se trouve la fenêtre du jeu, où est le curseur de la souris et si Alt est maintenue — pour placer les fenêtres du programme par-dessus le jeu et vous permettre de cliquer dessus.

Presse-papiers

  • Ce qu’il surveilleUniquement son compteur de modifications. Le contenu n’est pas lu.
    Ce compteur est un nombre que tient Windows : il change à chaque copie.
  • Quand il lit le contenuUne seule fois, après votre copie d’un objet dans le jeu.
    Quand le compteur a changé alors que la fenêtre du jeu est active : c’est votre Ctrl+C ou votre Ctrl+Alt+C sur un objet. Dans toute autre fenêtre, le presse-papiers n’est pas ouvert du tout. Ce qui s’y trouvait avant le lancement du programme n’est pas lu.
  • Ce qu’il en gardeUniquement le texte de l’objet, et dans la seule mémoire du programme.
    Du texte uniquement, 200 000 octets au plus. Un texte qui ne commence pas par la ligne du jeu « Classe d'objet » est aussitôt écarté : il n’est ni conservé ni écrit où que ce soit. Le texte de l’objet ne vit qu’en mémoire ; quand vous appuyez sur « {{ui Надеть}} », l’objet est enregistré dans le fichier du héros comme équipé.
  • Copie par F2L’ancien contenu du presse-papiers est remis en place.
    Le programme mémorise le presse-papiers en entier (jusqu’à 32 Mo), appuie dans le jeu sur les touches de copie, lit l’objet une seule fois et remet dans le presse-papiers ce qui s’y trouvait. Ce qu’il a mémorisé, il ne le regarde pas.

Les touches qu’il écoute

  • F2 Comparer / {{ui Надеть}}Compare l’objet sous le curseur avec l’objet équipé.
    Un nouvel appui sur le même objet l’enregistre comme équipé. Fonctionne aussi avec Alt maintenue.
  • F3 {{ui Закрыть}}Ferme la fenêtre du programme la plus en avant par-dessus le jeu.
  • F7 Programme ↔ jeuFait passer la fenêtre du programme au premier plan, et revient au jeu.
  • Quand il les écouteUniquement tant que la fenêtre du jeu est active.
    F7 — aussi dans la fenêtre du programme lui-même. Dès qu’une autre fenêtre est active, les touches sont libérées : dans les autres programmes, elles fonctionnent comme d’habitude. Si le jeu utilise lui-même l’une d’elles, le programme prend la suivante encore libre parmi F2, F3, F7, F6, F9, F10, F11. F4 n’est jamais prise.
  • Les autres touchesAucun intercepteur de clavier : le programme ne les voit pas.
    Les autres touches sur lesquelles vous appuyez, le programme ne les voit pas. Une seule exception : Alt. Tant que les fenêtres par-dessus le jeu sont activées, le programme demande à Windows si elle est maintenue.

Ce qu’il envoie au jeu

  • Ctrl+Alt+CUne fois pour chacun de vos appuis sur F2.
    Uniquement tant que la fenêtre du jeu est active. Ce sont les touches du jeu lui-même : « copier l’objet avec sa description détaillée ». Si, dans le jeu, la description détaillée est assignée à une autre touche qu’Alt, c’est cette touche qui est pressée à la place d’Alt.
  • Rien d’autreNi chat, ni commandes, ni souris, ni minuteur.
    Ni messages ni commandes dans le chat, ni clics de souris, rien de déclenché par un minuteur, rien en réaction au journal ou à l’écran. « {{ui Надеть}} » et ce que vous cochez ne modifient que les données du programme lui-même.

Fenêtres par-dessus le jeu

  • Trois petites fenêtresLa liste de l’étape, la réponse à une copie d’objet, l’indication pour l’arbre.
    Elles se placent au-dessus de la fenêtre du jeu. Elles ne prennent jamais le focus, et la souris les traverse jusqu’au jeu — sauf quand Alt est maintenue avec le curseur sur une fenêtre, et sauf sur les boutons de la réponse.
  • Ce qu’il leur fautLe jeu en mode fenêtré ou en plein écran fenêtré.
  • Comment les désactiverAvec un seul interrupteur, dans « {{ui Настройки}} ».

Ce qu’il écrit sur le disque

  • %APPDATA%\PoE2 Runbook\Tout ce que le programme écrit pendant qu’il fonctionne.
    • plans\vos plans et ceux installés depuis le catalogue ; le plan fourni avec le programme y est placé au premier lancement
    • runs\un fichier par héros : les événements du journal, ce que vous avez coché, les objets que vous avez enregistrés comme équipés
    • filters\les copies des versions du filtre que le jeu a chargées
    • backup\les versions précédentes d’un plan, avant chaque modification ; les plans retirés
    • export\les fichiers de plans que vous avez enregistrés pour les partager
    • update\l’installateur d’une nouvelle version, après « {{ui Обновить}} » ; supprimé une fois l’installation faite
    • settings.jsonle dossier du jeu, la taille et la position de la fenêtre, vos choix dans « {{ui Настройки}} »
    • program.logce que le programme a fait pendant ce lancement ; les cinq lancements précédents sont conservés aussi
    • webview\le stockage du moteur de la fenêtre : les réglages propres aux pages et le cache
  • %LOCALAPPDATA%\Programs\PoE2 Runbook\Le programme lui-même. Seul l’installateur écrit ici.
    Les droits d’administrateur ne sont pas demandés pour cela.
  • Le dossier « Téléchargements »Un fichier de plan, après « {{ui Скачать файл плана}} ».
  • Les dossiers du jeuRien n’y est écrit.
    Ni dans le dossier du jeu, ni dans Documents\My Games\Path of Exile 2.
  • Après la désinstallationVos plans et vos héros restent.
    La désinstallation du programme laisse %APPDATA%\PoE2 Runbook en place : vos plans et vos héros s’y trouvent. Vous n’en avez plus besoin ? Supprimez le dossier vous-même.

Réseau

  • À votre sujetLe programme n’envoie rien, nulle part, ni sur vous ni sur votre partie.
    Il n’a ni compte, ni statistiques, ni rapports d’erreur.
  • Mises à jour et catalogue des plansAu lancement, puis toutes les 6 heures : quatre fichiers de ce site.

    Ces fichiers sont petits : le fichier de mise à jour update/latest.json et le catalogue des plans plans/index.json, chacun avec sa signature (.sig). Si le site n’a pas répondu (ou si le jeu est déjà plus récent que le programme alors que la nouvelle version n’est pas encore sortie), le programme redemande une demi-heure plus tard. Cela se désactive dans « {{ui Настройки}} » : « {{ui Проверять обновления}} ».

    Le programme demande aussi le catalogue des plans quand vous ouvrez la liste des plans dans « {{ui Редактор}} » — une fois par minute au plus. Si « {{ui Проверять обновления}} » est désactivé, le programme ne contacte pas ce site de lui-même : le catalogue n’est demandé que par le bouton « {{ui Спросить каталог}} ».

  • Ce que contient la requêteLa version du programme, et rien d’autre.
    Chacune de ces requêtes contient la version du programme (User-Agent: PoE2Runbook/<version>) : ni cookies, ni nom, rien sur votre partie. L’hébergeur, comme pour toute requête, voit votre adresse IP.
  • SignaturesLe programme vérifie lui-même les deux fichiers, et ne les lit qu’ensuite.
    Il les vérifie avec une clé intégrée au programme. Une mise à jour n’est acceptée que si sa version est plus récente que celle du programme.
  • TéléchargementUniquement après votre appui sur « {{ui Обновить}} » ou « {{ui Поставить}} ».

    Tant que vous n’avez pas appuyé sur « {{ui Обновить}} » ou « {{ui Поставить}} », rien n’est téléchargé ni installé.

    « {{ui Обновить}} » dans la barre du haut : le programme télécharge l’installateur à l’adresse indiquée dans le fichier signé, vérifie sa taille et son SHA-256, le lance et se ferme ; l’installateur installe la nouvelle version et l’ouvre.

    « {{ui Поставить}} » ou « {{ui Обновить}} » dans le catalogue : le programme télécharge le fichier du plan à l’adresse indiquée dans le catalogue signé, vérifie sa taille et son SHA-256, puis range le plan dans sa bibliothèque.

  • Les pages de la fenêtreServies depuis votre propre ordinateur, elles ne répondent qu’à lui.
    L’adresse est 127.0.0.1 : le programme se sert à lui-même les pages de sa fenêtre.
  • Le moteur de la fenêtreMicrosoft Edge WebView2, un composant de Windows.
    C’est lui qui dessine la fenêtre. Il appartient à Microsoft et peut contacter de lui-même les serveurs de Microsoft, comme le fait le navigateur Edge.
  • Le navigateurIl ne s’ouvre que sur un clic de votre part.
    Ce site, depuis la fenêtre « {{ui О программе}} » ; la page de l’auteur d’un plan, depuis le catalogue ; la page d’un filtre d’objets sur pathofexile2.com ; la page de téléchargement de WebView2 chez Microsoft, si ce composant est absent.

Les règles de Grinding Gear Games qu’il respecte

Règle de GGGUn programme qui fonctionne séparément du jeu est autorisé ; un programme qui modifie le jeu ou ses fichiers ne l’est pas.
PoE2 RunbookPoE2 Runbook est un programme à part : il lit le journal et ses propres fichiers, et ne modifie rien dans le jeu.
Règle de GGGUne touche qui agit dans le jeu, c’est vous qui appuyez dessus ; elle fait une seule chose bien définie et une seule action dans le jeu.
PoE2 RunbookF2 fait une seule copie par appui. Rien ne se déclenche sur un minuteur, ni d’après le journal, ni d’après l’écran.
Règle de GGGLe journal, le presse-papiers et l’écran peuvent être lus quand vous savez ce qui en est fait ; le presse-papiers et l’écran, une seule fois pour chacun de vos appuis sur une touche.
PoE2 RunbookCette page en est justement la liste. Le presse-papiers est lu une fois par copie ; l’écran n’est pas lu.
