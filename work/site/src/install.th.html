เวอร์ชันสาธารณะตัวแรกยังไม่ได้เผยแพร่

เวอร์ชันนั้นจะมาอยู่ที่นี่: โปรแกรมดาวน์โหลดได้จากเว็บไซต์นี้เท่านั้น

การเปิดครั้งแรก

ตัวติดตั้งยังไม่ได้ลงลายเซ็นดิจิทัล Windows จึงไม่รู้จักผู้เผยแพร่ สิ่งที่ใช้แทนลายเซ็นคือ SHA-256 ข้างปุ่ม “ดาวน์โหลด” ซึ่งแสดงว่าไฟล์ของคุณคือไฟล์เดียวกับที่เผยแพร่ในหน้านี้

ไม่แน่ใจว่าไฟล์เป็นของจริง

ไฟล์ของจริงดูได้จาก SHA-256 เปิดโฟลเดอร์ที่มีไฟล์ที่ดาวน์โหลดมา คลิกที่แถบที่อยู่ของ File Explorer พิมพ์ powershell แล้วกด Enter ในหน้าต่างที่เปิดขึ้นมา ให้รันคำสั่งนี้:

Get-FileHash "PoE2Runbook-Setup-*.exe"

เทียบค่าที่อยู่ใต้คำว่า Hash กับ SHA-256 ข้างปุ่ม “ดาวน์โหลด” ต้องตรงกันครบทั้ง 64 ตัวอักษร ตัวพิมพ์ใหญ่หรือตัวพิมพ์เล็กไม่สำคัญ ถ้าไม่ตรง อย่าเปิดไฟล์: ให้ดาวน์โหลดใหม่จากหน้านี้

Windows ไม่ยอมให้เปิดตัวติดตั้ง

ตัวติดตั้งยังไม่ได้ลงลายเซ็นดิจิทัล Windows จึงไม่รู้จักผู้เผยแพร่ จะมีหน้าต่าง “Windows ปกป้องพีซีของคุณ” (Windows protected your PC) ขึ้นมา ให้กด “ข้อมูลเพิ่มเติม” (More info) แล้วกด “เรียกใช้ต่อไป” (Run anyway)

เบราว์เซอร์อาจเตือนก่อนหน้านั้นอีก เพราะไฟล์แบบนี้มีคนดาวน์โหลดไม่บ่อย ให้เลือกเก็บไฟล์ไว้ได้เลย

ใน Windows 11 ที่เปิด “การควบคุมแอปอัจฉริยะ” (Smart App Control) ไว้ จะไม่มีปุ่ม “เรียกใช้ต่อไป”: การป้องกันนี้บล็อกตัวติดตั้งโดยสิ้นเชิง

ไม่มีสิทธิ์ผู้ดูแลระบบ

ไม่จำเป็นต้องมี ตัวติดตั้งจะติดตั้งโปรแกรมให้คุณคนเดียว ลงในโฟลเดอร์ %LOCALAPPDATA%\Programs\PoE2 Runbook

โปรแกรมหาเกมไม่เจอ

โปรแกรมหาเกมเอง: ทั้ง Steam และไคลเอนต์จากเว็บไซต์ของเกม ในไดรฟ์ใดก็ได้ ถ้าหาไม่เจอ โปรแกรมจะแจ้งและให้คุณเลือกโฟลเดอร์เกมเอง

สิ่งที่ต้องมี

  • Windows 10 หรือ Windows 11 แบบ 64 บิต
  • Microsoft Edge WebView2: Windows 11 มีมาให้แล้ว ส่วน Windows 10 จะติดตั้งให้ผ่าน Windows Update ถ้าเครื่องไม่มี โปรแกรมจะแจ้งและเสนอหน้าดาวน์โหลดของ Microsoft
  • Path of Exile 2 โปรแกรมแต่ละเวอร์ชันทำมาสำหรับเกมเวอร์ชันเดียว ซึ่งระบุไว้ข้างปุ่ม “ดาวน์โหลด”
  • เกมอยู่ในโหมด “หน้าต่าง” หรือ “เต็มจอในโหมดหน้าต่าง” สำหรับหน้าต่างซ้อนบนเกม

การอัปเดต

เมื่อมีเวอร์ชันใหม่ โปรแกรมจะแจ้งเอง และติดตั้งให้เมื่อกดปุ่ม “{{ui Обновить}}” เวอร์ชันใหม่จะติดตั้งทับเวอร์ชันเดิม: แผนและฮีโร่ของคุณยังอยู่

การถอนการติดตั้ง

ใน “การตั้งค่า” ของ Windows: “แอป” → PoE2 Runbook → “ถอนการติดตั้ง”
