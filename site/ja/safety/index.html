プログラムが読み取るもの、受け付けるキー、押すキー

ゲームの横で動く独立したウィンドウです。ゲームのログと設定を読み、3つのキーを受け付け、あなたが F2 を1回押すたびに、アイテムのコピー操作を1回だけゲームに送ります。ゲーム自体には、ファイルにもメモリにも、一切変更を加えません。

以下の各行は、プログラムのコードから書き出したものです。矢印のある行は開きます。

  • ゲームのファイル
  • Windows
  • クリップボード
  • キー
  • ゲームに送るもの
  • ゲームの上のウィンドウ
  • ディスク
  • 通信
  • GGG のルール

読むもの：ゲームのファイル

  • logs\Client.txtゲームのログ。読み取りのみ：エリア、ヒーローのレベル、報酬。
    ゲームのフォルダーにあります。プログラムの起動時にログ全体を読み、その後は新しい行を1秒に2回読みます。ここから取り出すもの：ゲームの起動と終了、入ったエリア、ヒーローのレベル（その行から、ヒーローの名前とクラスもわかります）、クエストの報酬、ヒーローの死亡、ゲームが読み込んだアイテムフィルター、パッシブスキルツリーでのクリック、ゲームのバージョン。チャットに流れる発言のうち、拾うのはプランが待っている NPC のセリフだけです。それ以外は保存しません。
  • poe2_production_Config.iniゲームの設定。読み取りのみ：フィルター、言語、ゲームのキー設定。
    Documents\My Games\Path of Exile 2 にあります。ファイルが変わるたびに読み直します。ここから取り出すもの：選択中のアイテムフィルター、クライアントの言語、ゲームで割り当てられているキー。プログラムのキーが、ゲームの使っているキーと重ならないようにするためです。
  • OnlineFilters\あなたのアカウントのアイテムフィルター。読み取りのみ。
    Documents\My Games\Path of Exile 2 の中のフォルダーです。ゲームがあなたのアカウントからダウンロードしたフィルターが入っています。読むのは、各フィルターの名前とルールです。フィルターを名前で表示し、選択中のフィルターがプランの探しているアイテムを隠しているときに警告するためです。ゲームが読み込んだフィルターは、バージョンごとのコピーがプログラム自身のフォルダーに残ります。
  • Steam のファイルとレジストリ読み取りのみ。ゲームのインストール先を見つけるためです。
    libraryfolders.vdf、appmanifest_2694490.acf。レジストリでは、Steam のフォルダーと、インストール済みプログラムの中の「Path of Exile 2」の項目。ゲームが見つからなければ、フォルダーは自分で指定します。

Windows に尋ねること

  • アクティブなウィンドウ前面にあるウィンドウと、その持ち主。ゲームのメモリは読みません。
    今どのウィンドウが前面にあり、どのプログラムのものか。それがゲームだと知るためです。
  • ゲームのウィンドウ、カーソル、Alt今どこにあるか。画面からは何も読み取りません。
    ゲームのウィンドウの位置、マウスカーソルの位置、Alt が押されているかどうか。プログラムのウィンドウをゲームの上に置き、クリックできるようにするためです。

クリップボード

  • 見ているものクリップボードの変更カウンターだけ。中身は読みません。
    カウンターは Windows が管理している数値で、コピーのたびに変わります。
  • 中身を読むとき1回だけ。あなたがゲーム内でアイテムをコピーした後です。
    ゲームのウィンドウがアクティブな間にカウンターが変わったとき。つまり、あなたがアイテムの上で Ctrl+C または Ctrl+Alt+C を押したときです。ほかのウィンドウでは、クリップボードを開くことすらありません。プログラムの起動前からクリップボードにあったものは読みません。
  • 残るものアイテムのテキストだけ。それもプログラムのメモリの中だけです。
    テキストのみ、最大 200,000 バイト。ゲームの「アイテムクラス」の行で始まらないテキストは、すぐに破棄します。保存せず、どこにも書き込みません。アイテムのテキストはメモリの中にだけあります。「装備」を押すと、そのアイテムが装備中としてヒーローのファイルに記録されます。
  • F2 によるコピークリップボードの元の中身は、元どおりに戻ります。
    プログラムはクリップボード全体を覚えておき（最大 32 MB）、ゲーム内でコピーのキーを押し、アイテムを1回読み取ってから、元の中身をクリップボードに戻します。覚えておいた中身をのぞくことはありません。

受け付けるキー

  • F2 比較 / 装備カーソルの下のアイテムを、装備中のものと比較します。
    同じアイテムの上でもう一度押すと、そのアイテムを装備中として記録します。Alt を押したままでも使えます。
  • F3 閉じるゲームの上の、プログラムの一番手前のウィンドウを閉じます。
  • F7 プログラム ↔ ゲームプログラムのウィンドウを前面に出し、またゲームに戻します。
  • 受け付けるときゲームのウィンドウがアクティブな間だけ。
    F7 は、プログラム自身のウィンドウでも受け付けます。別のウィンドウがアクティブになると、キーはすぐに解放されます。ほかのプログラムでは、いつもどおりに使えます。どれかのキーをゲーム自体が使っている場合、プログラムは F2、F3、F7、F6、F9、F10、F11 の中から、次に空いているキーを使います。F4 は決して使いません。
  • そのほかのキーキーボードフックはありません。プログラムには見えません。
    ほかに何を押しているかは、プログラムには見えません。例外は Alt だけです。「ゲームの上のウィンドウ」がオンの間、プログラムは Alt が押されているかどうかを Windows に尋ねます。

ゲームに送るもの

  • Ctrl+Alt+Cあなたが F2 を1回押すごとに1回。
    ゲームのウィンドウがアクティブな間だけ。これはゲーム自体のキー操作で、「アイテムを詳細な説明つきでコピーする」ものです。ゲーム内で詳細な説明が Alt 以外のキーに割り当てられている場合は、Alt の代わりにそのキーを押します。
  • それ以外は何もチャットも、コマンドも、マウス操作も、タイマーによる操作もありません。
    チャットへのメッセージやコマンドも、マウスのクリックも、タイマーによる操作も、ログや画面に反応した操作も送りません。「装備」とあなたのチェックが変えるのは、プログラム自身の記録だけです。

ゲームの上のウィンドウ

  • 3つの小さなウィンドウステップのリスト、アイテムのコピーへの回答、ツリーのヒント。
    ゲームのウィンドウの上に表示されます。フォーカスを奪うことは決してなく、マウスの操作はウィンドウを通り抜けてゲームに届きます。例外は、Alt を押したままカーソルをウィンドウに重ねているときと、回答のボタンです。
  • 必要な条件ゲームがウィンドウモードか、ウィンドウフルスクリーンモードであること。
  • オフにする方法「設定」のスイッチ1つで。

ディスクに書き込むもの

  • %APPDATA%\PoE2 Runbook\プログラムが動作中に書き込むものすべて。
    • plans\あなたのプランと、カタログから追加したプラン。プログラムに付属するプランは、初回起動時にここに置かれます
    • runs\ヒーローごとに1ファイル：ログのイベント、あなたのチェック、装備中として記録したアイテム
    • filters\ゲームが読み込んだフィルターの、バージョンごとのコピー
    • backup\プランの以前のバージョン（編集のたびに保存）。削除したプラン
    • export\共有するために保存したプランファイル
    • update\新しいバージョンのインストーラー（「更新」を押した後）。インストールが済むと削除されます
    • settings.jsonゲームフォルダー、ウィンドウのサイズと位置、「設定」で選んだ内容
    • program.log今回の起動でプログラムが行ったこと。その前の5回分も残ります
    • webview\ウィンドウのエンジンの保存領域：ページ自体の設定とキャッシュ
  • %LOCALAPPDATA%\Programs\PoE2 Runbook\プログラム本体。ここに書き込むのはインストーラーだけです。
    その際、管理者権限は求められません。
  • 「ダウンロード」フォルダープランファイル。「プランファイルをダウンロード」を押したとき。
  • ゲームのフォルダー何も書き込みません。
    ゲームのフォルダーにも、Documents\My Games\Path of Exile 2 にも書き込みません。
  • アンインストール後プランとヒーローは残ります。
    プログラムをアンインストールしても、%APPDATA%\PoE2 Runbook はそのまま残ります。あなたのプランとヒーローが入っているためです。不要なら、フォルダーを自分で削除してください。

通信

  • あなたについてあなたやあなたのプレイのことは、どこにも一切送信しません。
    アカウントも、統計の収集も、エラーレポートもありません。
  • 更新とプランのカタログ起動時と6時間ごとに、このサイトから4つのファイルを取得します。

    どれも小さなファイルです。更新ファイル update/latest.json とプランのカタログ plans/index.json、そしてそれぞれの署名（.sig）。サイトが応答しない場合や、ゲームがすでにプログラムより新しいのに新しいビルドがまだない場合、プログラムは30分後にもう一度問い合わせます。「設定」の「更新を確認」でオフにできます。

    プランのカタログは、「編集」でプランのリストを開いたときにも問い合わせます（多くても1分に1回）。「更新を確認」がオフの場合、プログラムが自分からこのサイトにアクセスすることはありません。カタログを問い合わせるのは、「カタログを問い合わせる」ボタンを押したときだけです。

  • リクエストの内容プログラムのバージョンだけ。ほかには何もありません。
    こうしたリクエストに含まれるのは、プログラムのバージョン（User-Agent: PoE2Runbook/<バージョン>）だけです。Cookie も、名前も、あなたのプレイに関する情報も含まれません。ホスティング側には、どんなリクエストでもそうであるように、あなたの IP アドレスが見えます。
  • 署名どちらのファイルも、プログラムが自分で検証し、その後で初めて読みます。
    検証には、プログラムに組み込まれた鍵を使います。更新を受け入れるのは、そのバージョンが自分のバージョンより新しい場合だけです。
  • ダウンロードあなたが「更新」または「追加」を押した後だけ。

    「更新」または「追加」を押すまで、何もダウンロードされず、何もインストールされません。

    プログラム上部のバーにある「更新」：プログラムは、署名済みファイルに書かれたアドレスからインストーラーをダウンロードし、サイズと SHA-256 を照合してから、インストーラーを起動して自分は終了します。インストーラーが新しいバージョンをインストールし、それを開きます。

    カタログの「追加」または「更新」：プログラムは、署名済みカタログに書かれたアドレスからプランファイルをダウンロードし、サイズと SHA-256 を照合して、プランを自分のライブラリに入れます。

  • ウィンドウのページあなた自身の PC から配信され、その PC にしか応答しません。
    アドレスは 127.0.0.1 です。プログラムは、自分のウィンドウのページを自分自身に配信しています。
  • ウィンドウのエンジンMicrosoft Edge WebView2。Windows のコンポーネントです。
    ウィンドウを描画しているのは、このエンジンです。Microsoft のもので、Edge ブラウザーと同じように、自分から Microsoft のサーバーにアクセスすることがあります。
  • ブラウザーあなたがクリックしたときだけ開きます。
    このサイト（「このプログラムについて」ウィンドウから）。プラン作者のページ（カタログから）。pathofexile2.com のアイテムフィルターのページ。WebView2 が入っていない場合は、Microsoft の WebView2 ダウンロードページ。

プログラムが従う Grinding Gear Games のルール

GGG のルールゲームとは別に動くプログラムは認められています。ゲームやそのファイルを変更するものは認められていません。
PoE2 RunbookPoE2 Runbook は独立したプログラムです。ログと自分のファイルを読み、ゲームには何も変更を加えません。
GGG のルールゲーム内で作用するキーは、あなた自身が押します。そのキーは決まった1つのことだけを行い、ゲーム内で1つの操作だけを実行します。
PoE2 RunbookF2 は、1回押すごとにコピーを1回行います。タイマー、ログ、画面をきっかけに実行されるものは何もありません。
GGG のルールログ、クリップボード、画面は、それらがどう扱われるかをあなたが知っている場合に読み取ることができます。クリップボードと画面は、あなたがキーを1回押すごとに1回だけです。
PoE2 Runbookこのページが、まさにその一覧です。クリップボードは、コピー1回につき1回だけ読み取ります。画面は読み取りません。

ルールは自分たちの言葉で言い換えたものです。出典は Path of Exile の開発者向けドキュメント（英語）です。GGG は個々のプログラムを承認していません。ルールは GGG のものであり、GGG が変更することがあります。
