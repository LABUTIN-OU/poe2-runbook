Wie du die Datei prüfst und was Windows fragen wird

Die erste öffentliche Version ist noch nicht erschienen.

Sie erscheint hier: Das Programm gibt es nur auf dieser Website zum Herunterladen.

Erster Start

Das Installationsprogramm ist noch nicht signiert, deshalb kennt Windows seinen Herausgeber nicht. Statt einer Signatur gibt es den SHA-256 neben der Schaltfläche „Herunterladen“: Er zeigt, dass deine Datei genau die ist, die auf dieser Seite veröffentlicht ist.

Ich bin nicht sicher, ob die Datei echt ist

Die echte Datei erkennst du an ihrem SHA-256. Öffne den Ordner mit der heruntergeladenen Datei, klicke in die Adressleiste des Explorers, tippe powershell ein und drücke Enter. Führe im Fenster, das sich öffnet, diesen Befehl aus:

Get-FileHash "PoE2Runbook-Setup-*.exe"

Vergleiche den Wert unter Hash mit dem SHA-256 neben der Schaltfläche „Herunterladen“. Alle 64 Zeichen müssen übereinstimmen; ob Groß- oder Kleinbuchstaben, ist egal. Stimmen sie nicht überein, starte die Datei nicht: Lade sie erneut von dieser Seite herunter.

Windows lässt mich das Installationsprogramm nicht starten

Das Installationsprogramm ist noch nicht signiert, und Windows kennt seinen Herausgeber nicht. Es erscheint das Fenster „Der Computer wurde durch Windows geschützt“. Klicke auf „Weitere Informationen“, dann auf „Trotzdem ausführen“.

Der Browser warnt vielleicht schon vorher: Eine solche Datei wird selten heruntergeladen. Behalte sie trotzdem.

Ist unter Windows 11 die „Intelligente App-Steuerung“ (Smart App Control) eingeschaltet, gibt es die Schaltfläche „Trotzdem ausführen“ nicht: Dieser Schutz blockiert das Installationsprogramm ganz.

Ich habe keine Administratorrechte

Die brauchst du nicht. Das Installationsprogramm installiert das Programm nur für dich – in den Ordner %LOCALAPPDATA%\Programs\PoE2 Runbook.

Das Programm hat das Spiel nicht gefunden

Das Programm sucht das Spiel selbst: Steam oder der Client von der Website des Spiels, auf jedem Laufwerk. Findet es das Spiel nicht, sagt es das und lässt dich den Spielordner angeben.

Was du brauchst

  • Windows 10 oder Windows 11, 64 Bit.
  • Microsoft Edge WebView2 – in Windows 11 ist es enthalten, unter Windows 10 wird es von Windows Update installiert. Fehlt es, sagt das Programm das und bietet die Download-Seite von Microsoft an.
  • Path of Exile 2. Jede Version des Programms ist für genau eine Spielversion gemacht – sie steht neben der Schaltfläche „Herunterladen“.
  • Das Spiel im Modus „Fenster“ oder „Vollbild-Fenster“ – für die Fenster über dem Spiel.

Aktualisierung

Eine neue Version meldet das Programm selbst und installiert sie per Klick auf „Aktualisieren“. Die neue Version wird über die alte installiert: Deine Pläne und Helden bleiben.

Sprachen des Programms

English, Русский, Deutsch, Español, Français, 日本語, 한국어, Português (Brasil), ไทย.

Das Spiel-Log liest das Programm in jeder dieser Client-Sprachen.

Deinstallieren

In den Windows-Einstellungen: „Apps“ → PoE2 Runbook → „Deinstallieren“.

Der Ordner mit deinen Plänen und Helden – %APPDATA%\PoE2 Runbook – bleibt an seinem Platz. Brauchst du ihn nicht mehr, lösche ihn selbst.
