Официальные адреса

poe2.labutin.gg

Это единственный официальный адрес программы. poe2runbook.com ведёт сюда.

Официальные сборки публикуются только на poe2.labutin.gg; сами файлы лежат в выпусках репозитория программы.

Сборка с любого другого адреса — не наша: перед запуском сверьте SHA-256 файла с тем, что стоит на странице «Установка».

Как добавить план в каталог

Каталог — это планы, которые игроки ставят прямо из программы: «Редактор» → «Каталог». Каждый план стоит там под именем автора и со ссылкой на него.

  1. Соберите план в редакторе программы.
  2. Сохраните его файлом: «Редактор» → «Скачать файл плана».
  3. Пришлите файл автору программы: . Напишите, каким именем вас подписать и на какую вашу страницу поставить ссылку.

Автор программы посмотрит план и добавит его в каталог. После этого план появится в программе у всех игроков.

Имя автора программа берёт только из каталога, не из файла плана: чужой план под вашим именем не появится.
