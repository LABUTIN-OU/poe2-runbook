Как сверить файл и о чём спросит Windows

Первая публичная сборка ещё не опубликована.

Она появится здесь: программа скачивается только с этого сайта.

Первый запуск

Установщик пока не подписан, поэтому Windows не знает его издателя. Вместо подписи — SHA-256 у кнопки «Скачать»: он показывает, что ваш файл — тот самый, что опубликован на этой странице.

Сомневаюсь, что файл настоящий

Настоящий файл узнаётся по SHA-256. Откройте папку со скачанным файлом, нажмите на адресную строку Проводника, наберите powershell и нажмите Enter. В открывшемся окне выполните:

Get-FileHash "PoE2Runbook-Setup-*.exe"

Сравните значение под словом Hash с SHA-256 у кнопки «Скачать». Совпасть должны все 64 знака; большие буквы или маленькие — не важно. Не совпало — не запускайте файл: скачайте его заново с этой страницы.

Windows не даёт запустить установщик

Установщик пока не подписан, и Windows не знает его издателя. Появится окно «Система Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

Браузер может предупредить ещё раньше: такой файл скачивают редко. Сохраните его всё равно.

В Windows 11 с включённым «Интеллектуальным управлением приложениями» кнопки «Выполнить в любом случае» нет: эта защита блокирует установщик совсем.

Нет прав администратора

Они не нужны. Установщик ставит программу только для вас — в папку %LOCALAPPDATA%\Programs\PoE2 Runbook.

Программа не нашла игру

Программа ищет игру сама: Steam или клиент с сайта игры, на любом диске. Если не нашла, она скажет об этом и даст указать папку игры.

Что нужно

  • Windows 10 или Windows 11, 64-разрядная.
  • Microsoft Edge WebView2 — в Windows 11 он есть, в Windows 10 его ставит Центр обновления Windows. Если его нет, программа так и скажет и предложит страницу загрузки Microsoft.
  • Path of Exile 2. Каждая сборка программы сделана под одну версию игры — она названа у кнопки «Скачать».
  • Игра в окне или в оконном полноэкранном режиме — для окон поверх игры.

Обновление

О новой версии программа скажет сама и поставит её по кнопке «Обновить». Новая версия ставится поверх прежней: ваши планы и герои остаются.

Языки программы

English, Русский, Deutsch, Español, Français, 日本語, 한국어, Português (Brasil), ไทย.

Лог игры программа читает на любом из этих языков клиента.

Удаление

В параметрах Windows: «Приложения» → PoE2 Runbook → «Удалить».

Папка с вашими планами и героями — %APPDATA%\PoE2 Runbook — остаётся на месте. Не нужна — удалите её сами.
