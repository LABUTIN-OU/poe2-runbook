How to add a plan to the catalogue

The catalogue holds the plans players install straight from the program: Edit → Catalogue. Each plan stands there under its author's name, with a link to the author.

  1. Build your plan in the program's editor.
  2. Save it as a file: Edit → Download plan file.
  3. Send the file to the program's author: . Say which name to put on the plan and which page of yours to link.

The program's author will look at the plan and add it to the catalogue. After that the plan appears in the program for every player.

The program takes an author's name only from the catalogue, never from the plan's file: somebody else's plan will not appear under your name.
