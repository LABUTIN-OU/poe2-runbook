What the program reads, listens to and presses

A separate window beside the game: it reads the game's log and settings, listens to three keys and sends the game one item copy for one press of F2 of yours. It changes nothing of the game itself — not its files, not its memory.

Reads: the game's files

  • logs\Client.txtThe game's log. Read only: zone, hero level, rewards.
    It is in the game's folder. The whole log is read at start, then the new lines twice a second. Taken from it: when the game starts and closes; the zone you enter; the hero's level — the hero's name and class come from these lines; quest rewards; deaths; the item filter the game loaded; your clicks in the passive tree; the game's version. Of everything said in chat, only the NPC lines your plan waits for are noticed; the rest is not stored.
  • poe2_production_Config.iniThe game's settings. Read only: filter, language, the game's keys.
    It is in Documents\My Games\Path of Exile 2; read again when the file changes. Taken from it: which item filter is selected, the client's language, and the game's key bindings — so that the program's keys never take a key the game uses.
  • OnlineFilters\Item filters from your account. Read only.
    A folder in Documents\My Games\Path of Exile 2: the filters the game downloaded from your account. Each filter's name and rules are read — to call a filter by its name and to warn when the selected filter hides an item your plan looks for. A copy of each filter version the game loads is kept in the program's own folder.
  • Steam's files and the Windows registryRead only, to find where the game is installed.
    libraryfolders.vdf, appmanifest_2694490.acf; in the registry — Steam's folder and the “Path of Exile 2” record of installed programs. If the game is not found, you point to its folder yourself.

Asks Windows

  • The active windowWhich window is in front. The game's memory is not read.
    Which window is in front now and which program owns it — to know that it is the game.
  • The game's window, the cursor, AltWhere they are now. Nothing is read from the screen.
    Where the game's window stands, where the mouse cursor is and whether Alt is held — to place the program's windows over the game and to let you click them.

Clipboard

  • What is watchedOnly the clipboard's change counter. The content is not read.
    The counter is a number Windows keeps: it changes with every copy.
  • When the content is readOnce, after your copy of an item in the game.
    When the counter changes while the game's window is active — that is your Ctrl+C or Ctrl+Alt+C over an item. In any other window the clipboard is not opened at all. What lay in it before the program started is not read.
  • What is keptOnly an item's text, and only in the program's memory.
    Text only, up to 200,000 bytes. A text that does not begin with the game's “Item Class” line is dropped at once: not stored, not written anywhere. An item's text is kept in memory only; when you press Equip, the item is saved in the hero's file as the worn one.
  • Copy by F2What was in the clipboard before is put back.
    The program remembers the whole clipboard (up to 32 MB), presses the game's copy keys, reads the item once and puts back what was there. What it remembered is not looked into.

Keys it listens to

  • F2 Compare / EquipCompares the item under the cursor with what the hero wears.
    Pressed again on the same item — records it as worn. Works with Alt held as well.
  • F3 CloseCloses the program's top window over the game.
  • F7 Program ↔ gameBrings the program's window forward, and back to the game.
  • When they are listened toOnly while the game's window is active.
    F7 — in the program's own window too. The moment another window is active the keys are released: in other programs they work as usual. If the game itself uses one of them, the program takes the next free one of F2, F3, F7, F6, F9, F10, F11. F4 is never taken.
  • Other keysNo keyboard hook is installed: the program does not see them.
    The program does not see what else you press. The one exception is Alt — while its windows over the game are on, the program asks Windows whether Alt is held.

What it sends to the game

  • Ctrl+Alt+COnce for each press of F2 of yours.
    Only while the game's window is active. It is the game's own “copy the item with its full description”. If the game binds the full description to a key other than Alt, that key is pressed in its place.
  • Nothing elseNo chat, no commands, no mouse, nothing on a timer.
    No chat messages or commands, no mouse clicks, nothing on a timer, nothing in answer to the log or the screen. Equip and your marks change the program's own records only.

Windows over the game

  • Three small windowsThe step list, the answer to a copied item, the passive tree hint.
    They stand above the game's window. They never take the focus, and the mouse goes through them into the game — except while Alt is held with the cursor over a window, and on the buttons of the answer.
  • What they needThe game in windowed or borderless full-screen mode.
  • How to turn them offOne switch in Settings.

What it writes to disk

  • %APPDATA%\PoE2 Runbook\Everything the program writes while it runs.
    • plans\your plans and the plans installed from the catalogue; the plan that comes with the program is put here at the first start
    • runs\a file per hero: events from the log, your marks, the items you recorded as worn
    • filters\copies of the filter versions the game loaded
    • backup\earlier versions of a plan, saved before each edit; removed plans
    • export\plan files you saved to share
    • update\the installer of a new version — after you press Update; removed once it is installed
    • settings.jsonthe game's folder, the window's size and place, your choices in Settings
    • program.logwhat the program did at this start; the five starts before it are kept too
    • webview\storage of the window's engine: the pages' own settings and cache
  • %LOCALAPPDATA%\Programs\PoE2 Runbook\The program itself. Only the installer writes here.
    Administrator rights are not asked for it.
  • Your Downloads folderA plan file, when you press “Download plan file”.
  • The game's foldersNothing is written into them.
    Neither into the game's folder nor into Documents\My Games\Path of Exile 2.
  • After removalYour plans and heroes stay.
    Removing the program leaves %APPDATA%\PoE2 Runbook in place — your plans and heroes. Delete the folder yourself if you do not need them.

Network

  • About youThe program sends nothing about you or your game anywhere.
    It has no account, no statistics, no error reports.
  • Updates and the plan catalogueAt start and every 6 hours — four files from this site.

    The files are small: the update file update/latest.json and the plan catalogue plans/index.json, each with its signature (.sig). If the site does not answer — or the game is already newer than the program and no new build is out yet — the program asks again in 30 minutes. It is switched off in Settings: “Check for updates”.

    The program also asks for the plan catalogue when you open the list of plans in Edit — at most once a minute. With “Check for updates” switched off the program makes no request to this site by itself: the catalogue is asked for only when you press “Ask for the catalogue”.

  • What a request carriesThe program's version and nothing else.
    Each of these requests carries the program's version (User-Agent: PoE2Runbook/<version>): no cookies, no name, nothing about your game. The hosting sees your IP address, as with any web request.
  • SignaturesThe program checks both files itself before it reads them.
    It checks them with a key built into it. An update is accepted only when its version is newer than the program's own.
  • DownloadsOnly after you press Update or Install.

    Nothing is downloaded or installed until you press Update or Install.

    Update in the header: the program downloads the installer from the address named in the signed file, compares its size and SHA-256, starts it and closes; the installer puts the new version in place and opens it.

    Install or Update in the catalogue: the program downloads the plan's file from the address named in the signed catalogue, compares its size and SHA-256 and puts the plan into its library.

  • The window's pagesServed from your own computer; they answer this computer only.
    The address is 127.0.0.1: the program serves the pages of its own window to itself.
  • The window's engineMicrosoft Edge WebView2, a component of Windows.
    It draws the window. It is Microsoft's, and it may contact Microsoft on its own, the way the Edge browser does.
  • Your browserOpened only on your click.
    This site — from the program's About window; a plan author's page — from the catalogue; an item filter's page on pathofexile2.com; Microsoft's download page for WebView2 when that component is missing.

The rules of Grinding Gear Games it follows

GGG’s ruleA program that runs separately from the game is permitted; one that changes the game or its files is not.
PoE2 RunbookPoE2 Runbook is a separate program: it reads the log and its own files and changes nothing of the game.
GGG’s ruleA key that acts in the game is pressed by you, does one fixed thing and makes one action in the game.
PoE2 RunbookF2 makes one copy per press. Nothing runs on a timer, by the log or by the screen.
GGG’s ruleThe log, the clipboard and the screen may be read when you know what is done with them; the clipboard and the screen — once per key press of yours.
PoE2 RunbookThis page is that list. The clipboard is read once per copy; the screen is not read.

The rules are retold here in our words. Source: the developer documentation of Path of Exile. GGG does not approve programs one by one; the rules are its own and may change.
