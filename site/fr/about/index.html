Comment ajouter un plan au catalogue

Le catalogue, ce sont les plans que les joueurs installent directement depuis le programme : « Éditeur » → « Catalogue ». Chaque plan y figure sous le nom de son auteur, avec un lien vers sa page.

  1. Composez votre plan dans l’éditeur du programme.
  2. Enregistrez-le dans un fichier : « Éditeur » → « Télécharger le fichier du plan ».
  3. Envoyez le fichier à l’auteur du programme : . Indiquez sous quel nom vous créditer et vers laquelle de vos pages faire pointer le lien.

L’auteur du programme examinera le plan et l’ajoutera au catalogue. Le plan apparaîtra ensuite dans le programme chez tous les joueurs.

Le programme ne prend le nom de l’auteur que dans le catalogue, jamais dans le fichier du plan : le plan de quelqu’un d’autre n’apparaîtra pas sous votre nom.
