Comment vérifier le fichier, et ce que Windows demandera

La première version publique n’est pas encore sortie.

Elle apparaîtra ici : le programme ne se télécharge que depuis ce site.

Premier lancement

L’installateur n’est pas encore signé, Windows ne connaît donc pas son éditeur. À la place de la signature, il y a le SHA-256 à côté du bouton « Télécharger » : il montre que votre fichier est bien celui qui est publié sur cette page.

Je doute que le fichier soit authentique

Le fichier authentique se reconnaît à son SHA-256. Ouvrez le dossier où se trouve le fichier téléchargé, cliquez dans la barre d’adresse de l’Explorateur de fichiers, tapez powershell et appuyez sur Entrée. Dans la fenêtre qui s’ouvre, exécutez :

Get-FileHash "PoE2Runbook-Setup-*.exe"

Comparez la valeur affichée sous le mot Hash avec le SHA-256 à côté du bouton « Télécharger ». Les 64 caractères doivent tous être identiques ; majuscules ou minuscules, peu importe. S’ils diffèrent, ne lancez pas le fichier : téléchargez-le de nouveau depuis cette page.

Windows m’empêche de lancer l’installateur

L’installateur n’est pas encore signé, et Windows ne connaît pas son éditeur. La fenêtre « Windows a protégé votre ordinateur » apparaît. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».

Le navigateur peut vous avertir encore plus tôt : un tel fichier est rarement téléchargé. Conservez-le quand même.

Sous Windows 11, quand le « Contrôle intelligent des applications » est activé, il n’y a pas de bouton « Exécuter quand même » : cette protection bloque complètement l’installateur.

Je n’ai pas les droits d’administrateur

Ils ne sont pas nécessaires. L’installateur installe le programme pour vous seulement, dans le dossier %LOCALAPPDATA%\Programs\PoE2 Runbook.

Le programme n’a pas trouvé le jeu

Le programme cherche le jeu lui-même : Steam ou le client du site du jeu, sur n’importe quel disque. S’il ne le trouve pas, il vous le dit et vous laisse indiquer le dossier du jeu.

Ce qu’il faut

  • Windows 10 ou Windows 11, 64 bits.
  • Microsoft Edge WebView2 : Windows 11 l’inclut déjà ; sous Windows 10, c’est Windows Update qui l’installe. S’il manque, le programme vous le dit et vous propose la page de téléchargement de Microsoft.
  • Path of Exile 2. Chaque version du programme est faite pour une seule version du jeu : elle est indiquée à côté du bouton « Télécharger ».
  • Le jeu en mode fenêtré ou en plein écran fenêtré, pour les fenêtres par-dessus le jeu.

Mise à jour

Le programme vous signale lui-même une nouvelle version et l’installe quand vous appuyez sur le bouton « Mettre à jour ». La nouvelle version s’installe par-dessus l’ancienne : vos plans et vos héros restent.

Langues du programme

English, Русский, Deutsch, Español, Français, 日本語, 한국어, Português (Brasil), ไทย.

Le programme lit le journal du jeu dans n’importe laquelle de ces langues du client.

Désinstallation

Dans les Paramètres de Windows : « Applications » → PoE2 Runbook → « Désinstaller ».

Le dossier de vos plans et de vos héros — %APPDATA%\PoE2 Runbook — reste en place. Vous n’en avez plus besoin ? Supprimez-le vous-même.
